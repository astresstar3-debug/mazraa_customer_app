# خطة تنفيذ واجهات «مزرعتي»

## نطاق التدقيق

- تم فتح وفحص جميع ملفات `AppImages` وعددها **89 صورة**.
- جميع المراجع بقياس `1440 × 2560` ونسبة `9:16`، وتعرض واجهة iOS داخل إطار جهاز. مساحة التصميم المنطقية المستنتجة تقارب `390 × 844` نقطة.
- يوجد **88 مرجعًا بصريًا فريدًا**؛ الملف `bac3e160-af06-11f1-911d-5b275731370b (1).png` مطابق بكسليًا لملف `سجل المزايدات.png`.
- شريط الحالة iOS ثابت تقريبًا عند 9:41، مع Safe Area علوية، ومؤشر Home سفلي. التطبيق نفسه سيستخدم SafeArea وشريط النظام الحقيقيين ولا يرسم إطار الجهاز المرجعي.
- صور التدقيق المصغرة موجودة في `docs/visual_audit/contact_sheet_01.jpg` حتى `contact_sheet_15.jpg`، وهي للاختبار والتوثيق فقط ولن تُستخدم داخل الواجهة.

### الكتابة

- الخط المرجعي عربي هندسي قريب من **Tajawal/IBM Plex Sans Arabic**. التنفيذ يستخدم خط النظام العربي المتاح مع fallback متناسق لتجنب اعتماد شبكي.
- Display `28–32 / 700`، Headline `22–24 / 700`، Title `16–18 / 700`، Body `13–15 / 400–500`، Caption `10–12 / 400`، Button `14–16 / 700`، Price `18–26 / 700`، Timer tabular `18–28 / 700`.
- ارتفاع السطر بين `1.25` و`1.45`، ومحاذاة RTL افتراضية.

### القياسات

- شبكة spacing: `4, 8, 12, 16, 20, 24, 32`.
- الهامش الأفقي العام: `16` نقطة، مع `20–24` في شاشات الحالة والنماذج.
- Radius: الحقول `12`، البطاقات `14–16`، الصور `12`، الأزرار `12–14`، Dialog/Sheet `24`.
- الأزرار الأساسية بارتفاع `48–52`، شريط التنقل `64–72` قبل Safe Area.
- الظلال خفيفة: blur `8–16`، إزاحة `0,2–4`، opacity `0.05–0.10`، مع حدود أفتح من الخلفية.

### الصور والقص

- صور المنتج تستخدم `BoxFit.cover` بنسبة تقارب `1:1` في البطاقات، و`16:9` أو `4:3` في التفاصيل.
- زخارف الأوراق محصورة في رؤوس/ذيول الشاشات والأزرار الكبيرة، ولا تُكرر بكثافة داخل المحتوى.
- الأصول الديناميكية (منتجات، حيوانات، محاصيل) تبقى في Data Source تجريبي قابل للاستبدال، ولا توضع داخل Widgets.

## طبقات المحتوى

```text
Presentation (screens + reusable widgets)
        ↓
Controllers / ChangeNotifier state
        ↓
Repositories (contracts)
        ↓
Local demo data sources (replaceable by API)
        ↓
Domain models
```

المحتوى التجريبي معزول في `data/datasources` و`data/repositories`، ولا توجد قوائم منتجات داخل الشاشات.

## التفاعلات والحالات

- Bottom navigation وTabs وgrid/list toggle وfilter sheets تعمل فعليًا.
- البحث يفلتر repository محليًا؛ المفضلة والسلة والكمية والمزايدة والمحفظة حالات قابلة للتغيير في الذاكرة.
- العدادات تستخدم Timer حقيقيًا، مع أرقام LTR tabular داخل السياق العربي.
- CTA يفتح مسار التفاصيل/الدفع/النتيجة المناسب؛ أزرار النسخ والمشاركة والإشعار تقدم feedback واضحًا.
- النماذج تتحقق من المدخلات الأساسية، والحوارات/Bottom sheets قابلة للإغلاق.

## استراتيجية الاستجابة والتحقق

- نقطة المرجع `390 × 844`، مع `LayoutBuilder` وحد أقصى للمحتوى على الأجهزة العريضة.
- الهوامش Directional وكل الشاشات RTL؛ الأرقام/الرموز التي تحتاج ترتيبًا ثابتًا تستخدم LTR محليًا.
- اختبار Widgets على `360×800` و`390×844` و`430×932`، ثم جهاز Android المتصل `SM-S918U` (`1440×3088`).
- لقطات الجهاز تحفظ تحت `docs/visual_qa/actual/`، والفروقات/الملاحظات في التقرير النهائي.
